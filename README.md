# Medical Appointment Platform

A healthcare platform connecting patients with doctors for online consultations and appointment management.

## What is this?

This is a web application that helps patients find and book appointments with doctors, and enables doctors to manage their schedules and conduct video consultations with patients.

## Key Features

**For Patients:**
- Browse and search for doctors by specialty
- Book appointments with available doctors
- Join video calls for online consultations
- View and manage your appointments

**For Doctors:**
- Create and manage your professional profile
- Set your availability and schedule
- View patient appointments
- Conduct video consultations with patients

**For Administrators:**
- Verify and approve new doctor registrations
- Manage platform users
- Configure system settings

## How it Works

1. **Sign Up** - Create an account as a patient or doctor
2. **Get Verified** - Doctors go through an admin verification process
3. **Book or Manage** - Patients book appointments, doctors manage their schedule
4. **Connect** - Meet via secure video calls for consultations

## Tech Stack

This platform is built with:

- **Next.js** - Modern web framework for fast, responsive pages
- **Supabase** - User authentication and data storage
- **Prisma** - Database management
- **Twilio** - Video call functionality
- **Tailwind CSS** - Clean, modern design
- **TypeScript** - Type-safe code for reliability
